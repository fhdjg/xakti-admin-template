Dokumentasi Xakti Admin

Panduan singkat cara kerja, struktur, theming, dan integrasi admin template.

Mulai menggunakan template

Xakti Admin adalah situs statis tanpa framework runtime.

  1. Buka frontend/index.html langsung di browser untuk memakai bundel mandiri.
  2. Untuk ES Modules dan pengembangan lokal, jalankan python3 -m http.server 8080 dari folder frontend/.
  3. Akses http://localhost:8080, lalu gunakan sidebar untuk berpindah halaman.
  4. Salin pages/blank.html bila ingin membuat halaman baru dengan app shell yang sudah tersedia.

Cara kerja arsitektur

Setiap halaman HTML memiliki app shell yang sama: sidebar, topbar, area konten, footer, dan panel Theme Customizer.

BagianPeran
index.htmlDashboard utama dan entrypoint produk.
pages/Template halaman dashboard, formulir, tabel, auth, error, dan contoh plugin.
assets/css/Token desain, pemetaan Bootstrap, layout, komponen, dan integrasi plugin.
assets/js/app.jsEntry ES Module yang menginisialisasi seluruh modul melalui window.XaktiAdmin.
assets/js/app.bundle.jsBundel non-module untuk pembukaan melalui file://.

Tema dan sidebar

Mode global memakai data-bs-theme Bootstrap dan mendukung Terang, Gelap, serta Sistem. Pengaturan disimpan di localStorage dengan prefiks xa:.

  • Klik ikon palet pada topbar untuk memilih mode, preset sidebar, aksen, dan radius.
  • Preset sidebar dapat diatur lewat atribut data-xa-sidebar-theme atau token CSS di assets/css/tokens.css.
  • Color picker menghitung foreground dan token turunan secara otomatis agar kontras tetap terbaca.
  • Sidebar desktop dapat dilipat dengan tombol topbar atau shortcut Ctrl/Cmd + B; pada layar kecil sidebar memakai Offcanvas.

JavaScript publik

API publik tersedia melalui satu namespace global berikut:

XaktiAdmin.theme.set('dark');
XaktiAdmin.sidebar.toggle();
XaktiAdmin.sidebarTheme.apply('emerald');
XaktiAdmin.toast.show({ title: 'Berhasil', message: 'Perubahan tersimpan.' });

Panduan pengembangan

  • Gunakan kelas komponen Bootstrap apa adanya; gunakan prefiks xa- hanya untuk elemen app shell yang tidak tersedia di Bootstrap.
  • Tambahkan JavaScript sebagai modul kecil di assets/js/modules/, lalu daftarkan inisialisasinya di app.js.
  • Edit CSS sumber, kemudian sinkronkan assets/css/app.min.css karena halaman produksi memuat berkas minified tersebut.
  • Gunakan ikon dari assets/icons/sprite.svg; jangan menambahkan CDN atau dependensi eksternal.
  • Setelah perubahan user-visible, perbarui CHANGELOG.md dan uji light/dark, sidebar desktop/mobile, keyboard, serta minimal dua preset.
