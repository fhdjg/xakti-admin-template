Project Structure

Map of the main folders and the CSS and JavaScript asset sizes used by Xakti Admin.

xakti-admin-template/                      
   ├── index.html                    # Dashboard entrypoint
   ├── documentation.html            # Usage documentation
   ├── project-structure.html        # Project structure and asset size page
   ├── pages/                        # Application page templates
   │   ├── auth/                     # Login, register, forgot password
   │   └── errors/                   # Error pages 403, 404, 500
   ├── assets/
   │   ├── css/                     # Tokens, theme, layout, components, plugins
   │   ├── js/                      # Entry module, modules, and utilities
   │   ├── icons/                   # Local Lucide SVG sprite
   │   ├── fonts/                   # Local Inter font
   │   └── vendor/                  # Local Bootstrap and Chart.js
   ├── CHANGELOG.md
   └── README.md

Entry Points and Asset Flow

Use the appropriate files depending on how the application is served.

Local HTTP Server

index.html loads Bootstrap, app.min.css, then the Bootstrap bundle and app.js as an ES Module.

Direct File Access

The browser uses app.bundle.js because ES Modules have security restrictions under the file:// protocol.

CSS Sources

app.css imports the source CSS. Served pages load app.min.css, so the bundle must be synchronized after CSS changes.
